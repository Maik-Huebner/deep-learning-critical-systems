# Deep Learning for Critical Systems

Production-oriented PyTorch project for risk-sensitive AI applications with a planned focus on financial time-series analysis and explainable model decisions.

## Status

**In development**

The repository structure and isolated PyTorch environment are prepared. The concrete implementation will be developed after the final requirements of the Deep Learning module project are available.

## Planned project goals

- reproducible data preparation
- financial time-series modelling
- transparent baseline comparisons
- deep learning with PyTorch
- structured training and evaluation workflows
- robustness and error analysis
- explainability and documented limitations
- risk-sensitive decision support
- reproducible experiments and technical documentation

## Technical foundation

- Python 3.13
- PyTorch 2.13
- Apple Metal Performance Shaders
- NumPy
- pytest
- Git and GitHub

Additional dependencies will only be added when required by the implemented project scope.
