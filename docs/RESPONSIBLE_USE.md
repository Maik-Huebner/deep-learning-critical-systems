# Responsible Use

This code demonstrates an auditable research workflow. It does not provide
financial advice and must not be presented as a reliable forecast, regulatory
control, bank-grade system or deployable trading strategy.

The most consequential failure mode is a missed stress increase: the selected
Transformer misses 493 of 537 such cases. Other risks include source revisions,
concept drift, regime changes, overlapping-window dependence, calibration error,
hardware-dependent training variation and unjustified interpretation of attention.

Any operational investigation would require, at minimum, a point-in-time data
pipeline, independent validation, walk-forward testing, calibration and threshold
analysis, monitoring, lineage, access controls, incident handling, human review,
domain governance and clear accountability. This repository supplies none of
those assurances.
