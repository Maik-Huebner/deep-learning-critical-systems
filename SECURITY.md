# Security Policy

This repository is a research and portfolio prototype, not an operational
financial system. Please report suspected vulnerabilities privately through
GitHub's security-advisory feature instead of opening a public issue.

Only the latest revision on `main` is maintained. Never include credentials,
customer data or confidential market data in a report. The included repository
audit catches a few common accidental commits; it is not a professional secret
scanner or a substitute for dependency and supply-chain review.
